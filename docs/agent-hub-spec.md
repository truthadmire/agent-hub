# Agent Hub 首版范围

Agent Hub 是在本机协作开发 Git 项目的免费 macOS 应用。用户选择仓库，输入可验收的目标，查看计划和分工，跟踪一个或多个外部编码 CLI，在独立工作区检查成果和验证记录，然后决定是否采用修改。

## 谁负责什么

| 职责 | 默认连接 | 调用时机 |
| --- | --- | --- |
| 负责人、后端、审查 | 官方 Codex CLI | 需求拆解、接口实现及必要审查 |
| 前端 | 官方 Antigravity CLI | 视觉设计与交互实现 |
| 测试 | 官方 DeepSeek Harness | 测试或明确的局部辅助任务 |

角色、连接、模型和预算可调整，只有一个可用连接时也能执行适用的任务。DSH 使用用户自己付费的 API key，凭据通过 macOS 钥匙串保存。没有可靠数据的额度与费用保留为未知。

## 使用流程

1. 从 Finder 启动，导入本地 Git 项目或创建新的项目。记录所选基线、已有更改、技术栈和项目验证配置。
2. 一张看板卡对应一个完整目标。任务在待开始、进行中、需要你和已完成之间按实际状态移动。取消或归档的历史可回看。
3. 计划描述角色、可并行工作、依赖、范围与验收。角色输入和任务输入分别绑定收件人，草稿和已排队的消息能恢复。
4. 各写入者在受管 worktree 中工作。调度限额、退出状态、取消意图、需求修订和成果身份在采用前检查。跨模型通过项目记录、提交、差异与实际检查交接。
5. 程序在集成后的代码版本上执行必要验证。验证失败时可有限修复；需要人工验收、缺少环境、持续冲突等情形提供处理入口。保留旧版本与失败记录。
6. 用户可查看统一差异、成果、静态或项目命令预览、验证和待办，并决定是否导出补丁或合入原项目。发布产品代码与发布用户项目分别授权。

## 工程与验收

首版使用一个原生桌面程序、SQLite 数据库和受管子进程。界面默认简体中文。开发与真实模型验收使用临时示例仓库，普通 CI 仅使用无凭据测试。首验平台为 Apple Silicon。正式安装包须通过 Developer ID、Apple 公证、票据、挂载和正常安装检查。首版不依赖云端 Hub、远程 worker 或团队账号。
